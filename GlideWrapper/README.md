# ВЗЛЁТ — APK-обёртка приложения Glide

Проект собирает **APK-файл**, который открывает приложение «База Знаний "ВЗЛЁТ"»
(`https://nifty-tin-9130.glide.page/dl/00d90a`) в полноэкранном WebView — со своей
иконкой, названием и корректной работой кнопки «Назад».

```
GlideWrapper/
├─ app/src/main/java/ru/vzlet/kb/MainActivity.java   ← вся логика обёртки
├─ app/src/main/res/…                                ← иконки, тема, экран «нет сети»
├─ app/build.gradle                                  ← ЗДЕСЬ адрес и версия
├─ tools/make_icons.py                               ← генератор иконок
└─ .github/workflows/build-apk.yml                   ← сборка APK в облаке
```

## Что получится и чего не будет

| | |
|---|---|
| ✅ Иконка «ВЗЛЁТ» на рабочем столе, без адресной строки браузера | ❌ Работы без интернета — контент по-прежнему живёт на серверах Glide |
| ✅ Вход в Glide (включая Google) не ломается | ❌ Push-уведомления Glide (в WebView не работают) |
| ✅ Загрузка файлов из приложения и скачивание вложений | ❌ Публикации в Google Play (политика Minimum Functionality) |

Это **не** локальная копия контента: приложение — облачный PWA, и APK лишь даёт
ему «нативный» запуск. Полный офлайн требует пересборки контента заново.

## Вариант 1 — сборка в облаке, без установки чего-либо (рекомендуется)

1. Создайте **приватный** репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Откройте вкладку **Actions** → workflow **Build APK** → **Run workflow**.
3. Через ~3–4 минуты в разделе **Artifacts** скачайте `vzlet-kb-apk.zip` → внутри `app-release.apk`.
4. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

Проект самодостаточен: adb, Android Studio и локальный SDK не нужны — всё делает runner.

### Если нужны обновления приложения

Без постоянного ключа каждая сборка подписывается новым случайным ключом, и
следующая версия не установится «поверх» (Android скажет «приложение не установлено»).
Чтобы обновления работали, создайте ключ один раз и добавьте 4 секрета репозитория
(*Settings → Secrets and variables → Actions*):

```bash
keytool -genkeypair -v -keystore release.jks -alias vzlet \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -dname "CN=Vzlet KB, O=Vzlet, C=RU"
base64 -w0 release.jks > release.jks.b64     # macOS: base64 -i release.jks -o release.jks.b64
```

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | содержимое `release.jks.b64` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `vzlet` |
| `KEY_PASSWORD` | пароль ключа |

`release.jks` храните отдельно: потеря ключа = невозможность обновить установленное приложение.

## Вариант 2 — локальная сборка (Windows)

Нужно: JDK 17 + Android SDK (platform 34, build-tools 34.0.0) + Gradle 8.9.

```powershell
# 1. JDK 17 и Android SDK (пример через winget)
winget install EclipseAdoptium.Temurin.17.JDK
winget install Google.AndroidStudio      # либо только commandline-tools

# 2. переменные окружения (разовая настройка)
setx ANDROID_HOME "$env:LOCALAPPDATA\Android\Sdk"
setx PATH "$env:PATH;$env:LOCALAPPDATA\Android\Sdk\platform-tools"

# 3. сборка
cd GlideWrapper
gradle :app:assembleRelease
# результат: app\build\outputs\apk\release\app-release.apk
```

Для локальной сборки можно положить рядом `keystore.properties`:

```properties
storeFile=release.jks
storePassword=пароль
keyAlias=vzlet
keyPassword=пароль
```

Без этого файла release-сборка подпишется debug-ключом (устанавливается, но не обновляется).

## Что менять под себя

| Что | Где |
|---|---|
| Адрес приложения | `app/build.gradle` → `buildConfigField "String", "START_URL", …` |
| Название на рабочем столе | `app/src/main/res/values/strings.xml` → `app_name` |
| Цвет темы и иконки | `res/values/colors.xml` → `brand_blue` (и перегенерировать иконки) |
| Иконка | `python tools/make_icons.py app/src/main/res` или заменить `mipmap-*/ic_launcher.png` + `drawable/ic_launcher_foreground.xml` |
| Идентификатор приложения | `app/build.gradle` → `applicationId` (менять только до первой установки) |
| Версия | `versionCode` / `versionName` в `app/build.gradle` |

## Что уже учтено в коде

- **Google OAuth**: из User-Agent убран токен `wv`, иначе Google блокирует вход внутри WebView; включены сторонние cookie.
- **Кнопка «Назад»** ведёт по истории WebView, а не закрывает приложение.
- **Нет сети** → экран «Нет подключения» с кнопкой «Повторить» (а не белая страница).
- **Файлы**: выбор файла для загрузки в Glide (`onShowFileChooser`) и скачивание через `DownloadManager` с cookie-сессией.
- **Внешние ссылки** (`mailto:`, `tel:`, чужие домены) открываются в браузере, а не внутри обёртки.
- **Поворот экрана** не перезагружает приложение (`configChanges`), состояние WebView сохраняется.
- **Без сторонних зависимостей** — только Android framework, поэтому сборка не ломается на версиях библиотек.

## Проверка после установки

1. Иконка «ВЗЛЁТ» появляется в списке приложений, запускается без адресной строки.
2. Навигация внутри приложения работает, «Назад» возвращает на предыдущий экран.
3. Вход в приложение (если включён) проходит — особенно через Google-аккаунт.
4. В авиарежиме показывается экран «Нет подключения», после включения сети «Повторить» возвращает приложение.
5. Открытие вложения/файла скачивается в «Загрузки».

## Ограничения, о которых стоит помнить

- Поддомен `nifty-tin-9130.glide.page` принадлежит Glide и лицензирован отзывно: если его
  переименуют или приложение удалят, APK перестанет открывать контент (код обёртки это не лечит).
- Glide официально не поддерживает упаковку PWA в APK — при проблемах со стороны Glide
  рассчитывать на их поддержку нельзя.
- Публикация такого APK в Google Play почти наверняка будет отклонена; для внутреннего
  распространения используйте прямую раздачу файла или MDM.
- Раздача APK третьим лицам — только с согласия владельца приложения (у вас оно есть).

## Альтернатива без сборки

Если нужен результат за пару минут и адресная строка не мешает: [PWABuilder](https://www.pwabuilder.com/)
→ вставить URL → Android → скачать пакет. Получится TWA-обёртка поверх Chrome; выглядит
чуть менее «нативно» (виден адрес при переходе по внешним ссылкам) и зависит от Chrome.
